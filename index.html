ייצוא ללוח שנה

ייצא את הפגישות שלך כקובץ .ics — עובד עם Google Calendar, Apple Calendar ו-Outlook.

טווח ייצוא
איך לייבא ל-Google Calendar
1. לחץ "הורד קובץ .ics"
2. פתח calendar.google.com
3. הגדרות ⚙️ ← ייבוא וייצוא
4. בחר את הקובץ ← ייבא
💡 טיפ: iPhone — לחץ פעמיים על הקובץ. Outlook: קובץ ← ייבא/ייצא.
Google Drive — אחסון נתונים

חבר את האפליקציה ל-Google Drive שלך כדי לשמור את כל הנתונים בענן.
הנתונים יישמרו בקובץ serene-data.json בתיקיית Drive שלך.
נדרש Client ID מ-Google Cloud Console.

איך מקבלים Client ID? (מדריך 5 דקות)
שלב 1 — עבור ל console.cloud.google.com
שלב 2 — צור פרויקט חדש
שלב 3 — APIs & Services → Enable APIs → חפש Google Drive API → Enable
שלב 4 — Credentials → Create Credentials → OAuth client ID → Web application
שלב 5 — ב-Authorized JavaScript origins הוסף: file://
שלב 6 — העתק Client ID → הדבק למעלה
שלב 7 — OAuth consent screen → הוסף אימייל כ-Test user
